# 0002. Python 3.14 instead of 3.13

- **Status:** Accepted
- **Date:** 2026-10-14

## Context

The project target was Python 3.13. The build environment only provides Python
3.14, and Django 6.1.2 supports it.

## Decision

Use **Python 3.14** for development and the virtual environment. Keep code
compatible with 3.13+ so a downgrade remains possible.

## Consequences

- All dependencies in `requirements/*.txt` install cleanly under 3.14.
- Some libraries may lag in 3.14 wheel coverage; `psycopg[binary]` and Pillow
  installed successfully.
- The declared target remains 3.13; no 3.14-only syntax is required.
